# Security policy

## Supported versions

Only the **latest release** of Scrollback gets fixes. Please update (Settings → Updates →
**Check for update**) before reporting a problem.

## Reporting a vulnerability

Please **don't** open a public issue for security problems.

Email **[admin@homelabgate.lol](mailto:admin@homelabgate.lol)** instead, with:

- what the problem is and what someone could do with it,
- the steps to reproduce it,
- the Scrollback version (Settings → About) and your Android version.

Please leave out your own passwords, server addresses and personal files. A short, made-up
example is enough.

You should get a reply within a week. Once a fix is released, the problem is described in the
release notes, and you're credited if you want to be.

## What Scrollback stores

Scrollback has no account, no analytics and no server of its own. Your library, likes, notes and
server sign-ins stay on your phone, and it only connects to the servers you add yourself.
