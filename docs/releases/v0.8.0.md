# Scrollback v0.8.0: notes and archives

Two new tools in the Files tab: a Markdown notes editor and an archive manager.

## What's new

- **Notes.** A Markdown and plain-text editor with **Edit** and **Preview**. A formatting toolbar
  covers headings, bold, italic, strikethrough, lists, tasks, quotes, code and links. Notes save
  automatically a moment after you stop typing, and there's a word count.
  - Tap any `.md` or `.txt` file in Files to open it here.
  - Or use **Files → Tools → Notes** and pick a notes folder. An **Obsidian vault works**:
    `[[wikilinks]]` and `#tags` show in the preview, and front matter is left untouched.
- **Archives.** Extract **ZIP**, **TAR**, **TAR.GZ/BZ2/XZ**, **7z** and single **GZ/BZ2/XZ** files,
  either right where they are or into a new folder. Select files and tap **Compress** to make a ZIP.
  - Safe by default: existing files are never overwritten, files that try to escape the folder are
    refused, links are skipped, and extraction stops on suspicious "zip bomb" archives.
  - Works in local folders, folders you picked with Android's folder picker, and SFTP/SMB servers.
  - Password-protected archives aren't supported yet.
- **Swipe between sub-tabs.** Swipe left or right on **Library** and **Music** to move between
  their sections.

## Good to know

- The feed doesn't use the sideways swipe, because there it's used for seeking and zooming pictures.

## Install

Scrollback needs **Android 13 or newer**. Download the APK for your phone from the
[Releases page](https://github.com/PouryaFA81/Scrollback/releases), open it, and allow
**Install unknown apps** when Android asks. If you already have the release build, you can also
update from **Settings → Updates → Check for update**. See the
[README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick and how to install
with adb.
