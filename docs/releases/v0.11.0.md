# Scrollback v0.11.0: Nearby share

Send and receive files over Wi-Fi with phones and computers running LocalSend or RSend. No internet
or account needed.

## What's new

- **Nearby share.** Open it from **Files → Tools → Nearby share**, select files in Files and tap
  **Send nearby**, or pick **Nearby share** in any app's share sheet.
- **Find devices automatically.** Devices on the same Wi-Fi show up on their own. If one doesn't,
  use **Add by address**.
- **You decide what comes in.** Incoming files ask you to **Accept** or **Decline** first. Turn on
  **Quick save** to skip the question.
- **Your settings.** Received files go to `Download/Scrollback` unless you choose another folder.
  You can set the device name others see, and an optional **Receive PIN** that senders must enter.
- **Private and battery-friendly.** Transfers are encrypted (HTTPS). Scrollback only listens while
  the Nearby share screen is open or a transfer is running, and shows a notification while it works.
- **Also new:** CSV and TSV files now appear under **Documents** in Files, and recent documents in
  Files open in Scrollback.

## Good to know

- On **Android 17**, the first time you open Nearby share, Scrollback asks for the **Nearby
  devices** (local network) permission.
- The other device needs LocalSend or RSend open.
- **Credits:** Nearby share is a Kotlin port of RSend by the same author. It follows the public
  LocalSend v2 protocol. LocalSend is a separate project, and no LocalSend code is included.

## Install

Scrollback needs **Android 13 or newer**. Download the APK for your phone from the
[Releases page](https://github.com/PouryaFA81/Scrollback/releases), open it, and allow
**Install unknown apps** when Android asks. If you already have the release build, you can also
update from **Settings → Updates → Check for update**. See the
[README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick and how to install
with adb.
