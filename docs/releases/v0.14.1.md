# Scrollback v0.14.1: privacy clean-up

A small release that tidies up how you pick a VERT server for file conversion. Everything else is
the same as v0.14.0.

## What's new

- **VERT server: vert.sh or Custom.** In **Files → Tools → Convert (VERT) → VERT server**, choose
  **vert.sh** (the default, run by the VERT team) or **Custom**. Custom lets you enter your own VERT
  URL and video server (vertd) URL. Both are saved only on your phone. If you already set up your
  own server, it's kept and shows as **Custom**. See
  [File conversion with VERT](https://github.com/PouryaFA81/Scrollback/blob/main/docs/guide/file-conversion.md).
- **No personal setup in the project.** The built-in preset for a personal VERT server is gone, and
  the docs, roadmap and tests now use generic examples.
- **For contributors:** a new `scripts/check-private.sh` checks the repository and release notes
  against a local list of private details before each release.

## Good to know

- **Downloads:** three signed APKs plus `SHA256SUMS`, the same as v0.14.0. arm64-v8a (most phones
  from the last few years) is about 34 MiB, armeabi-v7a (older 32-bit phones) about 30 MiB, and
  universal (any phone) about 53 MiB.

## Install

Scrollback needs **Android 13 or newer**. Download the APK for your phone from the
[Releases page](https://github.com/PouryaFA81/Scrollback/releases), open it, and allow
**Install unknown apps** when Android asks. If you already have the release build, you can also
update from **Settings → Updates → Check for update**. See the
[README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick and how to install
with adb.
