# Scrollback v0.10.0: Office

Open PDFs and Office documents right inside Scrollback, and edit CSV tables.

## What's new

- **Office.** Open **Files → Tools → Office**, tap a document in Files, or choose
  **Open with Scrollback** from another app.
- **PDF**: swipe between pages, pinch or double-tap to zoom, tap the page counter to jump to a page,
  and search with highlighted matches (on Android 15 and newer, for PDFs that contain text).
- **Word (DOCX)**: headings, bold and italic, bulleted and numbered lists and tables. You can select
  the text.
- **Excel (XLSX)**: every sheet as a grid, with the values and the last calculated formula results.
- **PowerPoint (PPTX)**: slide titles, text, pictures and speaker notes.
- **CSV / TSV**: tap a cell to edit it, insert or delete rows, add columns, then **Save**, or
  **Save as…** to make a copy.
- **Text and Markdown** files open in the notes editor.

## Good to know

- Word, Excel and PowerPoint files are view-only. Older `.doc`, `.xls` and `.ppt` files aren't
  supported; open them in another app with the open-in icon.
- Password-protected PDFs aren't supported yet.
- The whole Office tool adds only about 145 KB to the app.

## Install

Scrollback needs **Android 13 or newer**. Download the APK for your phone from the
[Releases page](https://github.com/PouryaFA81/Scrollback/releases), open it, and allow
**Install unknown apps** when Android asks. If you already have the release build, you can also
update from **Settings → Updates → Check for update**. See the
[README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick and how to install
with adb.
