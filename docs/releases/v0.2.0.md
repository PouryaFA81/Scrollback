# Scrollback v0.2.0: a built-in file manager

Scrollback gets a **Files** tab, so you can tidy up your saved clips without leaving the app.

## What's new

- **Files home**: storage summary, categories (Videos, Images, Audio, Documents, Downloads and
  Installation files), recent files and your folders.
- **Folder browser** with breadcrumbs, list or grid view, sorting, and search in the current folder.
- **Manage files**: long-press to select, then copy, move, rename, delete, share, open with
  another app or view info. Create new folders.
- **Add source**: turn any folder into a Scrollback source in one tap.
- **All files access is optional.** By default Scrollback only works with the folders you pick. If
  you want to browse your whole internal storage like a regular file manager, you can turn on All
  files access yourself. Nothing else needs it.
- The bottom navigation bar now looks the same on every tab and over videos.

## Good to know

- The file manager is new and still in early testing. Deleting is permanent, so please double-check
  before you confirm.

## Install

Scrollback needs **Android 13 or newer**. There is no signed APK for this release yet (APK downloads on the Releases page: coming soon). To try it, build a debug APK with `./scripts/build-apk.sh` and install it with `adb install -r dist/scrollback-debug.apk`. See the [README](https://github.com/PouryaFA81/Scrollback#install) for details.
