# Scrollback v0.9.0: convert with VERT

Convert videos, images, audio and documents with [VERT](https://vert.sh), an open-source file
converter.

## What's new

- **Convert (VERT).** Open **Files → Tools → Convert (VERT)**, or select a file in Files and tap
  **Convert**.
- **Videos** convert on a VERT video server (vertd). Pick the format (MP4, WebM, MKV, MOV, AVI, GIF,
  WebP, APNG, M4V or 3GP) and **Fast**, **Balanced** or **Quality**. Scrollback uploads the file,
  shows live progress, saves the result to `Download/Scrollback/`, and then asks the server to
  delete its copy.
- **Images, audio and documents** open in the VERT web app, which converts them inside your browser,
  so nothing is uploaded.
- **Choose your server.** The default is vert.sh, run by the VERT team. You can set your own VERT
  instance and its video server instead, add an optional extra header for a server behind a login
  proxy (stored encrypted), and tap **Test** to check the connection.
- Clear messages when you're offline or the server can't be reached. Conversions can be cancelled.

## Good to know

- Converting a video uploads it to the video server you chose. Use your own server if you'd rather
  keep files at home.
- VERT and vertd are separate open-source projects by the VERT team. Scrollback only talks to them
  over the network.

## Install

Scrollback needs **Android 13 or newer**. Download the APK for your phone from the
[Releases page](https://github.com/PouryaFA81/Scrollback/releases), open it, and allow
**Install unknown apps** when Android asks. If you already have the release build, you can also
update from **Settings → Updates → Check for update**. See the
[README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick and how to install
with adb.
