# Scrollback v0.7.0: network storage

Scrollback can now open your SFTP servers and SMB shares, and stream their videos and pictures
straight into your feeds.

## What's new

- **Network storage.** Open **Files → Tools → Network storage** and tap **Add server**. Choose
  **SFTP** (sign in with a password or a private key) or **SMB** (SMB2/3 shares on Windows, Samba or
  a NAS; leave the user empty for guest access). **Connect & save** checks the connection before
  saving.
- **Browse and manage.** Saved servers appear under **Files → Locations**. Browse folders, create
  new ones, rename, delete and share. Opening or sharing a file downloads it to the app's cache first.
- **Stream into your feeds.** Tap **Add to feeds** on a server (or **Add source** on a folder) and
  its videos and pictures show up in the Feed and Pictures tabs, with seeking.
- **Host keys you can trust.** The first time you connect to an SFTP server, Scrollback shows its
  fingerprint and asks **Trust this server?** After that the key is pinned, and Scrollback refuses
  to connect if it ever changes.
- **Encrypted credentials.** Passwords and keys are encrypted with a key from the Android Keystore,
  like your other server accounts.

## Good to know

- SFTP was tested end to end. SMB folder listing was tested, but reading files from SMB still needs
  testing on a real Samba or Windows share. Please report anything that doesn't work.
- Release APKs are now just under 10 MiB each, mostly because of the libraries needed for modern SSH
  encryption.

## Install

Scrollback needs **Android 13 or newer**. Download the APK for your phone from the
[Releases page](https://github.com/PouryaFA81/Scrollback/releases), open it, and allow
**Install unknown apps** when Android asks. If you already have the release build, you can also
update from **Settings → Updates → Check for update**. See the
[README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick and how to install
with adb.
