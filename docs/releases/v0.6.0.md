# Scrollback v0.6.0: updates from inside the app

Scrollback can now update itself, and every release comes with signed APKs you can install
directly.

## What's new

- **In-app updates.** Open **Settings → Updates** and tap **Check for update**. Scrollback looks
  at the latest GitHub Release, picks the APK for your phone's processor, makes sure it is really
  Scrollback and signed with the same key, and hands it to Android to install. It only checks when
  you tap: there are no background checks.
- **Signed release APKs.** Each release now has three signed APKs, about 5.5 MiB each:
  **arm64-v8a** (most phones from the last several years), **armeabi-v7a** (older 32-bit phones)
  and **universal** (any phone, if you're not sure). There is also a universal debug APK for
  testing and a `SHA256SUMS` file to check your download.
- **Optional GitHub token.** While the repository is private, the update check needs a read-only
  GitHub token, which you can save under **Settings → Updates → GitHub token**. It is encrypted on
  your phone and only sent to GitHub's API. Once the repository is public, no token is needed.
- **A public roadmap.** [ROADMAP.md](https://github.com/PouryaFA81/Scrollback/blob/main/ROADMAP.md)
  lists what's coming next, in order: SFTP and SMB, notes, archives, file conversion with VERT, an
  Office viewer, a full movie player and Jellyfin video.

## Good to know

- Android asks you to allow Scrollback to **install unknown apps** the first time you install an
  update, and asks you to confirm each install.
- Release builds (`app.scrollback`) and debug builds (`app.scrollback.debug`) are **separate
  apps** with separate data. If you used a debug build before, installing the release APK adds a
  second app; it doesn't take over the old one's library. If you use Nextcloud, turn on
  **Sync library** first so your likes, notes, tags, history and playlists can follow you.
- The file manager, Nextcloud, the music servers and in-app updates are still new and in early
  testing. Please report anything that doesn't work as expected.

## Install

Scrollback needs **Android 13 or newer**. Download the APK for your phone from the
[Releases page](https://github.com/PouryaFA81/Scrollback/releases/latest), open it, and allow
**Install unknown apps** when Android asks. See the
[README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick and how to install
with adb.
