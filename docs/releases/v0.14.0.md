# Scrollback v0.14.0: server connections, hidden duplicates and an open-source license

Server connections that survive redirects and VPNs, one copy of each song when two servers share a
music folder, and Scrollback is now free software.

## What's new

### Server connections

- **Redirects keep working.** Scrollback now follows redirects itself. Your sign-in is kept when a
  server moves you from http to https or to another path on the same server. It isn't passed on to
  a different host, or from https down to plain http, unless that address is one you set up for the
  server.
- **Alternate address.** Each Nextcloud, Subsonic / OpenSubsonic and Jellyfin server can have a
  second address, for example `http://192.168.1.10:4533` at home and a VPN address away. Scrollback
  uses the one that worked last and switches automatically when it can't connect. Find it under
  **Settings → Servers → (your server) → Alternate address**.
- **Test connection.** Checks each address and explains in plain words what went wrong: redirects,
  names that can't be found, timeouts, certificates or a rejected sign-in. The reachability check
  for each address gives up after 20 seconds. If redirects lead to another address, tap **Use** to
  save it as the alternate address.
- **Smarter sign-in.** Adding a server saves the address it really answers on, and Nextcloud sign-in
  stays on the address that worked.

### Hide duplicates across servers (music)

- If the same songs are on two servers (for example Nextcloud Music and Navidrome sharing one
  folder), turn on **Hide duplicates across servers** in **Settings → Music** or
  **Settings → Servers** to show each song once.
- Songs are matched by title, artist, album and length (and track number when both copies have one).
- Choose which source plays first on the **Servers** screen. A "2 sources" label marks merged songs;
  long-press one (or **More → Play from…**) to pick a copy. Likes apply to every copy.
- This only changes what you see. Nothing is deleted on any server or on your phone.

## Good to know

- **Using a VPN on your phone?** If it sends all traffic through the tunnel, your home servers may
  be unreachable. Turn on **LAN bypass** or **split tunneling** in your VPN app, or set the server's
  alternate address.
- Long second lines in list rows now end with an ellipsis.
- **Downloads:** three signed APKs plus `SHA256SUMS`. arm64-v8a (most phones from the last few
  years) is about 34 MiB, armeabi-v7a (older 32-bit phones) about 30 MiB, and universal (any phone)
  about 53 MiB.

## Install

Scrollback needs **Android 13 or newer**. Download the APK for your phone from the
[Releases page](https://github.com/PouryaFA81/Scrollback/releases), open it, and allow
**Install unknown apps** when Android asks. If you already have the release build, you can also
update from **Settings → Updates → Check for update**. See the
[README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick and how to install
with adb.
