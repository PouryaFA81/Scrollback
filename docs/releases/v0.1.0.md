# Scrollback v0.1.0: first release

> Note for the maintainer: v0.1.0 was never tagged. It corresponds to commit `d83cf5a`. Create the
> tag before publishing these notes, or publish them without a release.

Meet Scrollback: a private, offline, TikTok-style feed for the videos and pictures you've saved on
your phone.

## Highlights

- **Your folders, your feed.** Pick any number of folders; Scrollback scans them, subfolders
  included, and keeps a private index on your phone.
- **Random** feed with reshuffle, and a **Saved** feed sorted newest or oldest first.
- **Pictures** grid with a full-screen viewer.
- **Like** with a double-tap, **save to playlists**, add **notes and tags**, **share** and see
  **info** for every item.
- **Library** with Liked, Playlists (create, rename, delete, reorder, play), History that resumes
  where you left off, and Search across names, folders, notes and tags.
- **Playback speed** from 0.5× to 2×, and loop each video or auto-advance.
- **PIN lock** that re-locks after 30 seconds in the background, **hidden items** only visible after
  unlocking, and **Block screenshots**.
- **Duplicate finder** that finds byte-identical copies and deletes extras only after you confirm.
- **Completely offline**: this version doesn't even have the internet permission.

## Install

Scrollback needs **Android 13 or newer**. There is no signed APK for this release yet (APK downloads on the Releases page: coming soon). To try it, build a debug APK with `./scripts/build-apk.sh` and install it with `adb install -r dist/scrollback-debug.apk`. See the [README](https://github.com/PouryaFA81/Scrollback#install) for details.
