# Scrollback v0.5.0: a simpler home

This release reorganises Scrollback so everything is easier to find. Nothing was taken away; it just
lives in a more sensible place.

## What's new

- **Five tabs, no more.** The bottom bar now has **Feed**, **Pictures**, **Music**, **Files** and
  **Library**. If you turn Music off, you get four.
- **One Feed tab.** Switch between **Random** and **Saved** at the top of the feed. The reshuffle
  button (Random) or the newest/oldest button (Saved) sits right next to the switch.
- **Settings behind the gear.** Settings and your servers now open from the gear at the top of the
  screen.
- **Library upgrades.** **Duplicates** is now in the Library, and **Hidden items** is always listed
  when you have a PIN. Tap it and enter your PIN to see them.
- The music mini player now floats above the bottom bar on every tab except the Feed.

## Good to know

- The file manager, Nextcloud and the music servers are still new and in early testing. Please
  report anything that doesn't work as expected.

## Install

Scrollback needs **Android 13 or newer**. This release has only a debug APK (`scrollback-0.5.0-universal-debug.apk`, app id `app.scrollback.debug`) and a `SHA256SUMS` file. Signed release APKs start with v0.6.0, so we recommend the [latest release](https://github.com/PouryaFA81/Scrollback/releases/latest). See the [README](https://github.com/PouryaFA81/Scrollback#download) for which APK to pick.
