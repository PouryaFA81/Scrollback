# File conversion with VERT

[← Guide index](README.md)

> **Coming soon.** File conversion is **not available in Scrollback yet**. This page will be filled
> in when the feature ships.

The plan is to let you convert files with [VERT](https://vert.sh), an open-source file converter,
from inside Scrollback. Details such as which formats are supported, and whether conversion happens
on your phone or on a server, have not been decided yet.

Until then, you can use the file manager's **Share** or **Open with** actions to send a file to
another app that converts it. See [File manager](file-manager.md).
