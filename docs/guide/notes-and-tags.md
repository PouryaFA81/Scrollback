# Notes, tags and search

[← Guide index](README.md)

This page is about the notes and tags you attach to videos and pictures. To write and edit
Markdown or text files, see the [Notes editor](notes-editor.md).

## Add a note and tags

1. In any feed, tap **Notes** on the right.
2. The **Notes & tags** sheet opens.
   - **Description**: write anything you want to remember about the item, like a recipe name or
     where a clip came from.
   - **Tags**: type one or more tags, for example `#recipe #funny`. Separate them with spaces or
     commas. The `#` is optional, and tags are saved in lower case.
3. Tap **Save**.

Your note and up to six tags show at the bottom of the video in the feed.

## Search

Open **Library** and tap **Search**.

- Type in **Search names, notes, tags** to find videos and pictures by file name, folder, note or
  tag.
- Below the search box you'll see a chip for each tag with the number of items, like
  `#recipe · 12`. Tap chips to filter: with several chips selected, you get only the items that
  have **all** of those tags. Typing text as well narrows the results further by name or note.
- Tap a result to open the results as a feed.

Songs are searched separately, from the search button on the **Music** tab.
