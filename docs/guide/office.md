# Office documents

[← Guide index](README.md)

Since v0.10.0, Scrollback opens PDFs, Word, Excel and PowerPoint files, and edits CSV tables. It
works offline.

## Open a document

- Tap a document in [Files](file-manager.md), including in the **Documents** category.
- Open **Files → Tools → Office** and tap **Open a document…**, or pick one under **Recent**.
- From another app, choose **Open with → Scrollback**.

## What each viewer does

| File | What you can do |
|---|---|
| **PDF** | Swipe between pages, pinch or double-tap to zoom, and tap the page counter to jump to a page. **Search** highlights matches on Android 15 and newer, for PDFs that contain text. |
| **Word (DOCX)** | Read paragraphs, headings, bold and italic text, bulleted and numbered lists, and simple tables. You can select the text. |
| **Excel (XLSX)** | See every sheet as a grid, with the values and the last calculated formula results. Number and date formats aren't applied. Very large sheets show the first 5,000 rows and 200 columns. |
| **PowerPoint (PPTX)** | See slide titles, text, pictures and speaker notes, in slide order. |
| **CSV / TSV** | Edit a table: tap a cell to change it, long-press a row to insert or delete rows, and add rows and columns. **Save** writes the file back; if the folder is read-only, **Save as…** makes a copy. Comma, semicolon and tab separators are detected. |
| **Text and Markdown** | Open in the [Notes editor](notes-editor.md). |

In **Tools → Office** you can also start a **New spreadsheet (CSV)**.

## Not supported

- Editing Word, Excel and PowerPoint files: these are view-only.
- Older `.doc`, `.xls` and `.ppt` files. Use the open-in icon to open them in another app.
- Password-protected PDFs.
