# Notes editor

[← Guide index](README.md)

Since v0.8.0, Scrollback has a Markdown and plain-text editor for `.md` and `.txt` files. (For the
notes and tags you attach to videos and pictures, see [Notes, tags and search](notes-and-tags.md).)

## Open a note

- Tap any `.md` or `.txt` file in [Files](file-manager.md). It opens in the editor.
- Or open **Files → Tools → Notes**. You see the notes in your notes folder, with **Search notes**
  at the top. Tap **+** to write a **New note**.

### Choose your notes folder

By default, notes live in Scrollback's own notes folder. Tap the folder row at the top of the notes
list to pick another folder, for example your **Obsidian vault**. Notes work in local folders,
folders you picked with Android's folder picker, and on [SFTP and SMB servers](network-storage.md).

## Write

- Switch between **Edit** and **Preview** at the top.
- The **formatting toolbar** adds headings, bold, italic, strikethrough, lists, tasks, quotes, code
  and links.
- Your note **saves automatically** a moment after you stop typing, and again when you leave. A word
  count shows how long it is.

## Preview

The preview shows headings, bold, italic and strikethrough, code blocks, quotes, lists and task
lists, tables, links, `[[wikilinks]]` and `#tags`. Front matter at the top of a file (the block
between `---` lines) is shown dimmed and never changed, so notes from Obsidian stay intact.

## Good to know

- Files larger than 2 MB open with another app instead.
- If a file can't be opened as text, Scrollback tells you so.
